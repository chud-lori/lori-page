## Summary

Lori is a **Senior Backend Engineer** who cares about the parts of a system where correctness has a direct business cost. The work tends to show up as results people can measure: revenue that stops leaking, new products shipped quickly and safely, and infrastructure costs cut by swapping paid dependencies for open-source ones that are run in-house.

Along the way, Lori has built services used by more than a million people a day and done the kind of performance work that turns seconds into milliseconds. Most of it is written in **Go** and **Python**.

Lori started out running Linux servers in vocational school and has a **security** background, with 1st place in the Network Security category at Gemastik 2018 and runner-up at the ICSW 2017 CTF. That bias still shapes the work, along with a preference for pragmatic architecture over novelty.

Outside work, Lori builds the tools that daily work seems to be missing. [Rusty Requester](https://github.com/chud-lori/rusty-requester) is a native API client in Rust that replaced Postman in Lori's own workflow, using around 10 MB of memory instead of 500 MB or more. [MiLog](https://github.com/chud-lori/milog) monitors nginx and small servers from a single bash file, with alerts to Discord, Slack, Telegram and Matrix and an optional eBPF probe for kernel events. [Go Boilerplate](https://github.com/chud-lori/go-boilerplate) is the Go service template Lori actually reuses, so a new service starts with clean architecture, caching and CI already in place. [Cornela](https://github.com/chud-lori/cornela) audits Linux containers for kernel-escape risk using Rust and eBPF, and [Agent Workbench](https://github.com/chud-lori/agent-workbench) gives AI coding agents a shared memory across sessions.
